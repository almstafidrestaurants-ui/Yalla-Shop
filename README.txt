Yalla Shop - HTML + CSS + JavaScript
==================================
1) Open index.html in Chrome or Edge.
2) All files must remain inside the same folder.
3) App opens with a 2.2-second splash screen.
4) Language: Arabic / English. Currency: USD / LBP.
5) Cart, favorites, language and currency are saved using localStorage.
6) Product data is illustrative and appears in app.js (PRODUCTS).
7) The exchange rate LBP_PER_USD=89500 is an EXAMPLE only; replace with an authoritative current rate or backend before launching.
8) Real commerce requires backend, authenticated users, order processing, payments, inventory, and delivery fees.
9) The splash picture is in assets/splash.png; logo in assets/logo.png.

Files:
- index.html
- style.css
- app.js
- assets/splash.png
- assets/logo.png
